# 书签秒搜 Bookmark Palette

一个只做「找书签 + 清理书签」的 Chrome 扩展：不改书签结构，用全局快捷键模糊搜索全部书签；体检页可查重复、无标题、HTTP 和失效链接，并支持安全删除（自动备份 + 撤销）。

## 功能

### 搜索

- **全局命令面板**：默认 `Ctrl+Shift+K`（macOS `Command+Shift+K`）呼出，覆盖当前页面，输入即搜。
- **搜索范围**：标题、URL、域名、完整文件夹路径。
- **中文/拼音**：中文关键词、全拼（`gongcheng`）、首字母（`gc` → 工程）。
- **排序**：匹配度 + 本地历史访问频次 + 最近访问（`history` 只读，不上传）。
- **结果信息**：标题、路径、域名；重复网址合并为一条并标注「重复 ×N」。
- **打开方式**：`Enter` 当前标签、`Ctrl+Enter` 新标签、`Shift+Enter` 新窗口、`Esc` 关闭。

### 体检与清理（扩展选项页）

- **重复 URL**：按规范化 URL（去 `www.`、去末尾斜杠、去 fragment、排序 query）分组；默认勾选每组除第一条外的成员。
- **无标题**：列出空标题书签，可补标题或删除。
- **HTTP**：列出 `http://` 书签，默认不选，便于逐条确认。
- **失效链接**：点击「扫描失效链接」后并发检测（HEAD，失败回退 GET，8 秒超时，8 并发，跳过 localhost/内网地址）。判定：
  - 404/410 → **失效**（默认勾选）
  - 401/403/405/429、5xx、DNS 失败、超时、连接失败 → **待确认**（不默认勾选；VPN/代理环境下尤其容易误判）
  - 2xx/3xx → 正常
- **安全删除**：
  - 只删除你勾选的行，删除前弹确认；
  - 自动下载一份 JSON 备份（标题/URL/路径）；
  - 记录「撤销上次」，可一键恢复（恢复到原文件夹与原位置）。
- **导出 CSV**：当前标签页的清单可导出。

## 安装

1. `npm install && npm run build`（或直接用已构建的 `dist/`）。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 「加载已解压的扩展程序」→ 选择 `dist` 目录。
4. 在 `chrome://extensions/shortcuts` 确认快捷键。

> Chrome 官方版从 137 起禁止命令行 `--load-extension`，必须用界面加载。

## 权限

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取索引、清理时删除 |
| `history` | 只读最近 90 天记录用于排序 |
| `scripting` + 站点访问 | 在当前页面注入搜索面板，不读取页面内容 |
| `storage` | 保存「撤销上次」所需的删除记录（本地） |

不联网上传；失效链接扫描需要向你书签里的网址发请求（只在你点击扫描时发生）。

## 清理注意事项

- 清理会**真正删除书签**，并与 Chrome 书签同步联动：若开启了书签同步，删除会同步到账号和其它设备。建议先确认同步状态。
- 「撤销上次」保存在 `chrome.storage.local`，只保留最近一次删除记录；卸载扩展或清除扩展数据会丢失。
- 失效判定是启发式，且会受 VPN/代理影响：超时、DNS 失败、403/429/5xx 都可能只是网络或反爬问题，所以这些一律标「待确认」且默认不勾选；只有明确的 404/410 才默认勾选。

## 开发

```bash
npm install
npm run build     # 产出 dist/
npm test          # 用本机 Chrome Bookmarks 快照跑搜索用例（只读）
```

修改源码后重新 `npm run build`，再到 `chrome://extensions` 点「重新加载」。

## 已知限制

- 失效检测只发 HEAD/GET，不解析页面内容；需要登录或强反爬的站点会被标「待确认」。
- 没有标签系统、新标签页仪表盘；死链扫描不保存历史结果，刷新后需重扫。
- 拼音词典约 500 KB，打包在 background.js。
